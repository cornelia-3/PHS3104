Devoir 3 de Mécanique Quantique II

## Configuration
Le projet est initialisé avec un environnement virtuel Python local et les dépendances nécessaires au notebook.

### Environnement local
- Python 3.13
- Bibliothèques : numpy, matplotlib, qutip

### Installation rapide
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### Vérification
```powershell
python -c "import numpy, matplotlib, qutip; print('ok')"
```
